1. CHROMIUM
-----------
This image runs a Chromium build: Chrome for Testing 155.0.8059.84 in the
public images, and Kernel's build of Chromium at the same upstream version in
the private images.

Chromium is licensed under the BSD 3-Clause license and incorporates several
hundred third-party components under their own licenses. The complete list,
with each component's license text, is available at:

    chrome://credits

    https://chromium.googlesource.com/chromium/src/+/refs/tags/155.0.8059.84

The complete source of those files, as they appear in this build, together with

2. FFMPEG (STANDALONE)
----------------------
This image contains an unmodified FFmpeg binary at /usr/local/bin/ffmpeg, with
ffprobe alongside it, used by the session recorder. It is a separate program:
nothing in Kernel's software links against it.

    version:  n7.1.5-12-g1fdbca85aa
    license:  GPL-3.0-or-later (built with --enable-gpl --enable-version3)
    source:   https://github.com/kernel/oss-source/releases/tag/ffmpeg-n7.1.5-12-g1fdbca85aa

That release contains the FFmpeg source at the commit this binary was built
from, and the build scripts used to compile it. The exact configure flags are
printed by running `ffmpeg -version` inside this image.
